# CoachTools icons

Place 512 × 512 PNG artwork here using the exact paths in `apps.json`:

```text
allstar.png
weekly-data.png
coaching-gaps.png
coach-timeline.png
kpi-impact.png
qa-scores.png
audit-checklist.png
```

These files are intentionally optional. Until an image is added, the desktop renders each application's configured initials in a polished CSS tile. Replacing an icon does not require editing application code.
