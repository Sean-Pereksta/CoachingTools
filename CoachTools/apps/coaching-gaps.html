Quick Help
Fast guide for first-time users.

Tabs

  • Individual Coach: Shows each rep’s timeline, coaching, and performance.
  • Team Report: Shows team-level summaries and compares teams.
  • Team Analysis: Shows a deeper breakdown of the selected team.

Filters

  • Mode: Switches between Retail and Referral data.
  • Team: Chooses which team to view.
  • KPI: Picks the main metric being reviewed.
  • Multi View KPI: Adds another KPI for comparison.
  • Goal %: Sets the target percentage for success.
  • Start / End: Limits the date range.
  • Min KPI Coverage %: Requires enough KPI data before showing results.
  • Sort: Changes how reps are ordered.
  • Opportunity Gate: Filters out low-volume data.
  • Types: Chooses which coaching types to include.
  • Documented Coaching Filter: Lets you exclude certain coaching categories or wording.
  • Checklist Item: Filters checklist issues you want to track.
  • Keyword Phrase: Matches checklist descriptions by phrase.
  • SLA Aging: Colors checklist items by how old they are.
  • Data Docks: Selects which saved local data sources the dashboard should use.
  • Refresh: Rebuilds the report using current filters.
