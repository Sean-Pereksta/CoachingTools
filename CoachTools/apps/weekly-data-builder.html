How it works & file support

Add mode: Upload the appointment report, wiper report, and previous weekly data. The builder appends the new batch at the first blank row after history.

Modify mode: Upload the previous weekly data plus at least one source report. The builder finds rows matching the selected date and representative name, then previews only the columns supplied by that source. A wiper-only update touches wiper columns only; an appointment-only update touches appointment fields only. Blank source values leave existing cells unchanged.

Add new: In Modify mode, this inserts source representatives who are missing from the selected date directly after the final row in that date block. It is off by default.

Finalize modify: Modify mode is preview-first. Export stays locked until you review the impacted rows and select Finalize modify.

CSV, TSV, TXT, and unprotected XLSX files are supported. Tab-separated and UTF-16 reports are detected even when the filename ends in .csv. For older .xls files, save as .xlsx or CSV first. Commercial, Consumer, and Insurance are recognized above their Opportunities, Appointments, and Appt Rate columns. “Source columns” provides an override for other layouts.

Matching: A name match ignores capitalization and extra spaces, standardizes typographic apostrophes/dashes, and recognizes “Last, First.” It does not guess spelling. In Modify mode both the date and name must match before an existing row is touched.

Safety: Same names under different coaches stay separate; ambiguous matches are held for review instead of duplicated. Conflicting duplicate statistics remain blank unless you select a source row in Review. Exact duplicates and unnamed summary rows are skipped. Newly imported text that could execute as a spreadsheet formula is escaped; existing CSV cells are not rewritten.

Excel notes: XLSX imports read the selected worksheet’s saved values. The CSV export cannot retain workbook formatting, multiple tabs, macros, or live formulas. A workbook with unsaved formula results must be recalculated and saved, or exported to CSV first. CSV uses UTF-8 with an Excel-friendly byte-order mark. Files up to 50 MB are accepted; large Excel files have additional expansion limits.

Privacy: This is a self-contained file. It does not transmit reports, load remote scripts, save reports to browser storage, or modify the originals. Reopening the tool starts a fresh session.
